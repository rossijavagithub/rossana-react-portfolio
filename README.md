# Portfolio React - Rossana Maguiña

Portfolio profesional creado con React, Vite y React Router. Incluye cinco proyectos interactivos orientados a diseño, marketing digital, e-commerce, experimentación y email QA.

## Instalar y abrir

```bash
npm install
npm run dev
```

Después abre la dirección que muestra la terminal, normalmente `http://localhost:5173`.

## Crear versión de producción

```bash
npm run build
```

## Proyectos

- Alma Concept Store: filtros, búsqueda, favoritos y carrito.
- Brilla Festival: campaña, cuenta atrás y formulario.
- Nexo Insights: dashboard con periodos, KPIs y customer journey.
- Orbit Experiment Lab: hipótesis, variantes, métricas y resultado A/B.
- Luma Email Studio: preview responsive, personalización, QA y proof.

## Vercel

Importa el repositorio desde GitHub. Vercel detectará Vite automáticamente. El archivo `vercel.json` permite abrir las rutas internas de React Router directamente.
