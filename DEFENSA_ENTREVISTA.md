# Defensa breve del portfolio

## Presentación

> Mi portfolio refleja mi perfil híbrido: diseño la identidad y la experiencia, y después la desarrollo con React, HTML, CSS y JavaScript. Quise enseñar proyectos distintos, pero conectados con marketing, conversión, analítica y control de calidad.

## React utilizado

- Componentes reutilizables para cabecera, presentación y tarjetas.
- React Router para navegar sin recargar la aplicación.
- `useState` para menús, carrito, favoritos, filtros, formularios, QA y modales.
- `useEffect` para la cuenta atrás del festival y el scroll de navegación.
- `useMemo` para filtrar productos y calcular resultados A/B.
- Renderizado de arrays mediante `map()`.

## Conexión con Adobe Journey Optimizer

- Brilla representa una landing de conversión enlazada desde una campaña.
- Alma genera comportamientos que pueden convertirse en eventos: producto visto, carrito y compra.
- Nexo representa reporting de entregas, aperturas, CTR y conversiones.
- Orbit reproduce el planteamiento de un content experiment A/B.
- Luma reproduce el flujo de contenido, personalización, test profile, responsive QA y proof.

## Aclaración honesta

> Son casos de estudio frontend y de diseño. La relación con AJO está planteada a nivel de flujo y experiencia, ya que AJO requiere una licencia y un sandbox empresarial. No simulo que exista una integración real que no está implementada.
